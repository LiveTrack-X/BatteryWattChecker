# ChargeWatts

Windows 작업표시줄 시계 옆에서 **충전 중에는 배터리에 들어가는 전력(W)**을, **배터리로 사용할 때는 노트북이 배터리에서 소모하는 전력(W)**을 볼 수 있습니다. 숫자는 5초마다 갱신됩니다.

## 다운로드 및 실행

1. [최신 릴리스에서 ChargeWatts.exe 다운로드](https://github.com/LiveTrack-X/ChargeWatts/releases/latest/download/ChargeWatts.exe)
2. 파일을 보관할 폴더에 저장하고 실행하세요. 숫자가 보이지 않으면 작업표시줄의 숨겨진 아이콘 메뉴(`^`)에서 시계 옆으로 끌어오세요.
3. 다음 로그인 때도 표시하려면 아이콘을 우클릭하고 **로그인할 때 자동 시작**을 선택하세요. 같은 메뉴에서 자동 시작을 해제하거나 앱을 종료할 수 있습니다.

## 숫자 읽는 법

| 표시 예시 | 의미 |
| --- | --- |
| 초록색 `36` | 배터리가 약 36W로 충전 중입니다. 마우스를 올리면 35.7W처럼 소수점 한 자리까지 표시합니다. |
| `−12` | 지금 노트북이 배터리에서 약 12W를 사용하고 있습니다. |
| `0` | 충전 대기 중이거나 전력이 반올림하면 0W입니다. 마우스를 올리면 상태를 구분할 수 있습니다. |
| `?` | Windows에서 사용할 수 있는 배터리 전력 측정값이 없습니다. |

측정 기준은 **배터리에 들어가거나 배터리에서 나오는 전력**입니다. 충전기에 적힌 정격 출력이나 USB-C 포트의 총 입력 전력과는 다를 수 있습니다. 앱은 Windows WMI의 `root\wmi`에서 첫 번째 활성 `BatteryStatus`를 읽습니다. 배터리가 여러 개인 기기에서는 해당 배터리 하나의 값이 표시됩니다.

## 소스에서 빌드

Windows에서 .NET Framework 4.x의 C# 컴파일러를 사용합니다. 저장소 폴더에서 PowerShell로 실행하세요.

```powershell
.\build.ps1
.\bin\ChargeWatts.exe
```
